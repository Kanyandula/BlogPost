API Documentation

REST API for NyasaBlog — Token-based authentication required.

Obtaining an Authentication Token

POST

/api/account/login

Params:

username — Enter your login email

password — Your password

Response:

{ "response": "Successfully authenticated.", "pk": 1, "email": "user@nyasablog.com", "token": "27a46967801960..." }

Creating a Blog Post

POST Auth required

/api/blog/create

Headers:

Authorization: Token <token>

Params:

title (text)

body (text)

image (file)

Viewing a Specific Blog Post

GET Auth required

/api/blog/<slug>/

Updating a Specific Blog Post

PUT Auth required, author only

/api/blog/<slug>/update

Deleting a Specific Blog Post

DELETE Auth required, author only

/api/blog/<slug>/delete

List Blog Posts

GET Auth required, paginated

/api/blog/list/?search=<query>&ordering=-date_updated&page=1

Query Params:

search — Search title and body

ordering — title, body, username, date_updated

page — 10 results per page
